# How I like to work

This is my work laptop. Keep work here, and don't pull in my personal projects.

## Writing to me
- Plain words, no jargon. If a technical term is needed, explain it in a few words the first time.
- I skim. Keep the replies in the format you'd normally use, with headings, short bullets and tables, but keep them tight. Don't add a "short version" unless I ask.
- Short labels and one-sentence explanations. If a screen needs a paragraph, it needs a redesign.
- Say plainly what's done, what you checked, and what failed. Don't call something working until you've run it.

## Pages and visuals
- Light theme by default.
- Design for both phone (390px) and laptop (1280px). Don't just stretch one.
- Every chart gets a title and a one-line plain caption.
- One name per idea, used everywhere.

## Reviews and decisions
- When something long needs my input (a plan, a spec, options), use the **html-worker** skill so I can click and comment instead of reading paragraphs.
- My daily to-do list is the **daily-tasks** skill (Planner app). Today's goals are hand-typed by me. Never fill them in.

## Safety
- New Claude sessions stop at "Do you trust this folder?". That's my check. Never answer it for me.
- Ask before anything that's hard to undo, or that sends data outside this laptop.
